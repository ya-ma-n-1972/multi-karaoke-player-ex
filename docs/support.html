Multi Karaoke Player EX サポート

Multi Karaoke Player EXは、PCに保存したカラオケ動画を検索・予約し、曲ごとのキーを変えながら再生できるWindows向けアプリです。

動作環境

  • Windows 10 バージョン1809以降、またはWindows 11
  • x64のWindows PC
  • Microsoft Edge WebView2 Runtime
  • 利用者自身が用意した動画・音声ファイル

Windows 11 x64での利用を推奨します。

基本的な使い方

  1. 画面右下の「フォルダ設定」を開きます。
  2. カラオケ動画を保存しているフォルダーを追加します。
  3. 一覧から曲を選び、「予約」または「割り込み予約」を押します。
  4. 必要に応じて曲順とキーを調整します。
  5. 「次の曲を再生」を押します。

曲が一覧に表示されない場合

  • 「フォルダ設定」に正しいフォルダーが登録されているか確認してください。
  • 一覧の更新を実行してください。
  • サブフォルダー内も検索しますが、ショートカットやリンク先は対象外です。
  • 対応する動画拡張子は MP4、MKV、AVI、MOV、WMV、M4V、WebM、TS、FLV、MPG、MPEGです。
  • カラオケ曲情報ファイルの拡張子は .kvpsong です。

動画が再生できない場合

動画形式が一覧に表示されても、動画内の圧縮方式によっては標準方式で再生できない場合があります。互換モードを利用できる場合は再生前に確認画面が表示されます。WebView2に関するエラーが表示される場合は、Microsoft Edge WebView2 Runtimeが利用できる状態か確認してください。

キー変更

キーは－12～＋12半音の範囲で、予約前、予約後、再生中に変更できます。再生速度は変わりませんが、素材や変更幅によって音質が変化する場合があります。

カラオケ曲情報ファイル

.kvpsong ファイルには、ボーカル入り動画、ボーカルなし動画、別の伴奏音源、既定キーを一曲分としてまとめられます。元の動画や音声は埋め込まれないため、素材を移動または削除すると再生できなくなります。

保存される設定と履歴

設定、予約状態、直近20件の再生履歴は %LOCALAPPDATA%\KaraokePlayer-v0.9\ に保存されます。初期状態へ戻す場合は、アプリを終了してからこのフォルダーを削除してください。元の動画や音声は削除されません。

第三者ソフトウェア

互換モードは、LGPL 2.1以降で提供されるFFmpegのライブラリを使用します。ライセンス本文と作成情報はアプリに同梱しています。
