# Multi Karaoke Player EX

## 概要

Multi Karaoke Player EX は、PCに保存したカラオケ動画を検索・予約・連続再生できる Windows 向けカラオケプレーヤーです。Microsoft Store で配布します。

このリポジトリは、プライバシーポリシーとサポート情報の公開用です。
